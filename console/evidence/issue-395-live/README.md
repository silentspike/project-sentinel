# Issue 395 token-free UI evidence

These screenshots are generated by `console/e2e/issue-395.spec.ts` against the
locally built Console with Playwright-controlled API responses. They verify the
Agent Editor and Org Chart UI scope without contacting a Sentinel runtime or an
LLM provider.

| Evidence | Viewport | Covered state |
| --- | --- | --- |
| `desktop-org-chart-agent-editor.png` | 1920x1080 | Org Chart keyboard navigation, Agent Editor selection, tier update, save, and nano-runtime separation |
| `mobile-org-chart.png` | 390x844 | Narrow layout with no document-level horizontal overflow |
| `org-chart-error.png` | 1024x768 | Explicit projection/API error state; the same test also verifies the empty state |

The test fails on unexpected page errors, console errors, or failed requests.
The expected HTTP 503 console message in the deliberate error-state case is the
only allowlisted browser error.

No deployment, service restart, runtime target, real-provider request, or paid
token was used to create this evidence. Runtime acceptance and benchmarks remain
blocked by Gate B.
